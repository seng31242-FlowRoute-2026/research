# Contribution Guidelines

## Research Documentation Rules

Every research contribution must include:

- Date
- Author
- Source references
- Summary
- Key findings

---

## File Naming

Examples:

- interview-01.md
- competitor-analysis-notion.md
- routing-algorithm-research.md

---

## Commit Message Examples

docs(research): add competitive analysis for Trello

feat(interview): add findings from client interview #2

fix(research): update workload balancing references

---

## References

Use APA format for external references whenever possible.
